{{- else if eq .Values.elabftw.service.type "NodePort" }}

Get the application URL by running:

  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} \
    -o jsonpath="{.spec.ports[0].nodePort}" \
    services {{ include "elabftw.fullname" . }})

  export NODE_IP=$(kubectl get nodes \
    --namespace {{ .Release.Namespace }} \
    -o jsonpath="{.items[0].status.addresses[0].address}")

  echo http://$NODE_IP:$NODE_PORT

{{- else if eq .Values.elabftw.service.type "LoadBalancer" }}

Get the application URL by running:

  kubectl get svc --namespace {{ .Release.Namespace }} \
    -w {{ include "elabftw.fullname" . }}

{{- else if eq .Values.elabftw.service.type "ClusterIP" }}

The service is exposed internally as:

  {{ include "elabftw.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.elabftw.service.port }}

To access it locally, run:

  kubectl port-forward --namespace {{ .Release.Namespace }} \
    svc/{{ include "elabftw.fullname" . }} \
    8080:{{ .Values.elabftw.service.port }}

Then open:

  http://127.0.0.1:8080

{{- end }}
